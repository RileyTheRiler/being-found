# Interaction specification

The current sequence is select object, choose verb, walk to its spot, run an async chapter action. Keep the object menu for competing intentions. A single, reversible action should support one activation where its label already makes the consequence clear. Enter and touch must lead to the same state.

|Action proposal|Physical feedback|Consequence and alternative|
|---|---|---|
|Paint a window|Brush meets the particular pane, a mark appears, jar rings on release.|Mark persists into next Saturday. Set the brush down or leave. Offer named pane choices without dragging.|
|Carry the sign|Noor lifts it; its silhouette disappears from the wall.|It appears in Leena’s hands or remains at home. Allow deferral, with no penalty.|
|Serve tea|Cup moves from counter to table at contact. Caption the pour.|Later Dele finds the same cup cold only if it was left. Decline or leave without serving.|
|Work the chair arm|Walt indicates the grain; sanding changes the visible surface.|Walt can ask for another pass or put it aside. Provide a single untimed button.|

For each action specify the initiating person, interruption points, object owner, save boundary and final state. Match sound onset to contact. Cancel scene-owned callbacks on skip or quit. Keep direct observation separate from interpretation in the Notebook. The first production test is a playable painting sequence with sound muted and the Notebook closed.
